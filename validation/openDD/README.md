# Derived openDD validation summaries

These files contain aggregate validation outputs derived from openDD trajectories. Raw openDD trajectories are not redistributed.

The openDD analysis was used for empirical plausibility assessment, falsification, and model-form diagnosis rather than full calibration. L0-L4 are mechanistic response states, not empirically discovered driver classes.

`accepted_gap_proxy_s` is a geometric temporal-clearance proxy at detected roundabout entry and is not a critical-gap estimate. Absolute L2/L4 braking and jerk remain model-sensitive.
